Sync between devices off

Off, each device keeps its own records. On, every job, part line, restock line and setting appears on every device that holds the same sync key, usually within a second, and catches up after being offline. Photos stay on the device that took them.

One-time setup (about ten minutes, done once for the shop): the records are kept in a free Google Firebase database that only this key unlocks.

  1. Go to console.firebase.google.com, sign in with a Google account, Add project. Name it "Bond Shop Tracker"; turn Google Analytics off.
  2. Build ▸ Firestore Database ▸ Create database. Location: us-east1 (South Carolina). Start in production mode.
  3. On the database's Rules tab, replace everything with the rules below and Publish.
  4. Build ▸ Authentication ▸ Get started ▸ Sign-in method ▸ Anonymous ▸ Enable.
  5. Project Overview ▸ Add app ▸ Web (</>). Nickname "Shop Tracker", Register. Copy the firebaseConfig block it shows and paste it below.
Firestore rules
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /shops/{shop}/{document=**} {
      allow read, write: if request.auth != null && shop.size() >= 20;
    }
  }
}

Connected to project . To add a device, copy this key and paste it into Setup ▸ Sync on that device. Anyone holding the key can read and change the shop's records, so send it by text message or AirDrop, not by posting it anywhere.

Prompt for Use Model
You are reading text copied from the identification labels on a piece of outdoor power equipment (mower, generator, chainsaw, pressure washer, welder, ATV) and from its engine. The equipment label text comes first, then a line of dashes, then the engine label text.

Return ONLY a JSON object with exactly these keys: make, model, serial, date_of_manufacture, hours, engine_make, engine_model, engine_serial.

Rules:
- make is the equipment brand (for example Cub Cadet, John Deere, Troy-Bilt, Generac, Stihl).
- model is the equipment model number (the value after MODEL, MODEL NO or M/N).
- serial is the equipment serial number: the value after SERIAL, SERIAL NO, S/N, PIN or VIN.
- date_of_manufacture is the value after MFG DATE or similar, if present.
- engine_make is the engine brand (Briggs & Stratton, Kohler, Kawasaki, Honda, and so on).
- engine_model is the engine model plus any SPEC, TYPE or CODE values, separated by spaces.
- engine_serial is the engine's serial number.
- Copy characters exactly as written. Never guess, correct or complete a number.
- Use "" for anything that is not present.
- No explanation and no markdown. Output the JSON object only.
